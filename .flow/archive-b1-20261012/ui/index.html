实例页「发布」区块的七个冻结状态。每个文件为完整实例页快照（含发布区块），双击即可打开；全部零脚本。

契约状态 ↔ 原型文件
状态文件一句话说明
R1 表单默认态release-form.html版本号 + 变更说明 + 发布按钮（GET /instance）
R2 发布成功态release-success.html快照路径、index 追加位置、双指纹（POST 200 重渲染，表单复位）
R3 内容指纹警告态release-warn.html发布成功 + 警告条（含既有条目 package@version 对照，不阻断）
R4 校验失败态release-invalid.html实例校验问题逐行回显，零写盘，值保留（页面上下文含 2 个问题指标）
R5 版本号非法态release-semver.html非 semver 内联错误，值保留，零写盘
R6 重复版本拒绝态release-duplicate.html同 id@version 已发布：内联错误含「已发布于 …，请升级版本号」
R7 index.yaml 损坏拒绝态release-index-broken.htmlreleases/index.yaml 解析/形状非法：拒绝发布，指引 git 恢复
