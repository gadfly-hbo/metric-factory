M2 UI 原型导航

M2「零配置体验」两个用户可见表面的冻结状态：设置页（/settings，查看+覆盖）与首页（/）AI 模型芯片行（四分支三态）。每个文件为完整页面快照，双击即可打开；首页芯片/引导链接指向对应设置页状态文件（生产实现一律 /settings）。

原型约定

CSS 逐字取自 src/ui/render.ts 顶部 CSS 块，外加契约 §7.3 声明的两条增量（.chip-fail 红 chip、a.chip 去下划线），零其他新增类；全部文件不含 <script>（生产实现同为零客户端脚本）。

演示数据为虚构但镜像真实形状：打码 = maskKey 实际形状（****+末 4 位，如 ****e2f9）；错误文案逐字取自 src/llm/index.ts 工厂急错与 src/ui/server.ts 设置 422；链序 per G4 裁决 B（minimax-cn/MiniMax-M3 主 / xiaomi-token-plan-cn/mimo-v2.6-flash 备）。合成 auth.json 宇宙 = 7 个 provider（minimax-cn、xiaomi-token-plan-cn、openai、deepseek、kimi-coding、moonshot、zhipu），各状态间守恒（链外提示行数量随之增减）。

表单 action 按生产路径书写（/settings/save、/settings/clear）；首页芯片在原型内链接到对应设置页状态文件，生产实现一律 href="/settings"。
